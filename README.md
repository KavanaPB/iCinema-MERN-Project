## 📖 Project Overview

**iCinema** is a Full Stack MERN Movie Discovery and Trailer Streaming Platform inspired by modern OTT services such as Netflix and Prime Video.

The platform enables users to discover trending movies, search movies instantly, watch trailers, submit reviews, explore movie information, and experience a responsive cinematic user interface.

Built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**, the application demonstrates modern full-stack development practices including authentication, REST APIs, state management, responsive UI design, and database integration.

## 🚀 Installation & Setup

### Clone Repository

```bash
git clone https://github.com/KavanaPB/iCinema-MERN-Project.git
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## ⚙ Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=3000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key
```

---

## ▶ Running the Application

### Start Backend Server

```bash
npm run backend
```

### Start Frontend Application

```bash
cd frontend
npm run dev
```
